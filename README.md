# 🦴 MiColumna — Sitio Web del Consultorio Dr. Miceli

> 🏥 Sitio web médico para el **consultorio del Dr. Alberto Miceli**, especialista en columna vertebral ubicado en **Villa Devoto, Buenos Aires**. Atiende junto a la **Dra. Carolina Moughty Cueto** (Neurocirugía).

El objetivo del sitio es que pacientes con dolor de columna encuentren el consultorio, conozcan a los especialistas y puedan **agendar un turno fácilmente**. 📅
